# Óc Eo – Ba Thê WebGIS

WebGIS mô phỏng trực quan khu di tích Óc Eo – Ba Thê, tối ưu cho GitHub Pages.

## Tính năng
- Bản đồ 2D/3D bằng MapLibre GL JS.
- Terrain + hillshade từ DEM công khai, không cần API key.
- Chế độ bay tự động quanh Núi Ba Thê / không gian Óc Eo.
- Ranh giới bảo vệ **minh họa/tham khảo** và lớp khu vực khảo cổ.
- Điểm di tích, popup thông tin, điều hướng theo “story tour”.
- Thanh điều chỉnh độ phóng đại địa hình.
- Tour VR 360° riêng, liên kết từ WebGIS.
- Responsive cho desktop/mobile.

## Chạy
Mở `index.html` trực tiếp qua web server hoặc bật GitHub Pages từ nhánh `main`.

> Lưu ý: ranh giới và địa hình mô phỏng trên trang không thay thế dữ liệu đo đạc, hồ sơ pháp lý hoặc DEM chuyên ngành.
